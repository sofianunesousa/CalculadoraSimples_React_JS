
# 💜 Calculadora React JS

Uma calculadora simples e interativa desenvolvida com React JS, como atividade prática de Desenvolvimento de Sistemas.

O projeto permite realizar operações matemáticas básicas de forma fácil e intuitiva, utilizando componentes, estados e eventos do React.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🧮 Cálculo de dois números
- 🧹 Botão para limpar os campos
- 💜 Interface com design lilás e delicado
- 📱 Layout organizado e responsivo

## 🛠️ Tecnologias utilizadas

- **React JS** — Desenvolvimento da interface e gerenciamento de estados.
- **JavaScript** — Lógica das operações matemáticas.
- **CSS Modules** — Estilização dos componentes.
- **Vite** — Ferramenta utilizada para criação e execução do projeto.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd nome-do-projeto
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Acesse no navegador

Abra o endereço informado pelo Vite no terminal, geralmente:

```text
http://localhost:5173
```

## 📚 O que foi aprendido

Durante o desenvolvimento da calculadora, foram praticados conceitos importantes do React JS, como:

- Criação de componentes funcionais.
- Utilização do hook `useState`.
- Manipulação de eventos com `onClick`, `onChange` e `onSubmit`.
- Utilização de formulários em React.
- Criação de funções para realizar cálculos.
- Uso de CSS Modules para estilização.
- Organização de projetos React.
